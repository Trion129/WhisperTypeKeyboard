# WhisperType Daily-Driver IME Design

Date: 2026-08-14
Status: approved for implementation (user: drive to completion)

## Goal

Make WhisperType usable as a default Android keyboard: full emoji, autocomplete, transcription-limit warning, symbol/accent popups, clipboard history, plus daily-driver typing essentials.

## Product locks

- Architecture B: extract modules, keep the existing View IME.
- Autocomplete: on-device English wordlist + local unigram learning. Incognito required.
- Dictation: warn at 25s, hard-stop and transcribe at 30s.
- Emoji: full categorized Unicode catalog, search, recents, skin tones.
- Clipboard: last 20 text clips, persist, swipe or × delete.
- Daily-driver extras: number row, word-delete swipe, double-space period, sentence caps, globe, cursor bar.
- Backlog only: swipe-to-type, one-handed, resize, GIFs, themes, multilingual layouts, cloud sync, live captions, auto-chunk past 30s.

## Architecture

`WhisperKeyboardService` owns IME lifecycle.
`KeyboardController` is the only object that talks to `InputConnection`.
New units return actions; they do not commit text.

```
WhisperKeyboardService
        │
        ▼
KeyboardController
        ├── KeyboardLayout
        ├── KeyPopupCatalog
        ├── RecordingLimiter
        ├── SuggestionEngine
        ├── ClipboardStore
        ├── TypingRules
        └── panels: EmojiPicker, ClipboardPanel, CursorBar
```

## Chrome

Replace the 36dp status row with one shared strip:

- Default: suggestion strip — clipboard chip | 3 word candidates | emoji chip.
- Listening / transcribing / error: same slot shows status. Listening: `Listening · 12s · 18s left`. At 25s the strip uses warning color. At 30s it becomes `Transcribing on-device…`.

Key rows stay 4×48dp. LETTERS adds a 5th digit row (`1`–`0`) above QWERTY.
Cursor bar is a 36dp row under chrome, hidden until long-press space.
Globe sits on the bottom row and calls `switchToNextInputMethod(false)`, hidden when switching is not offered.

## Recording limiter

- Hard stop: 30_000 ms of captured PCM.
- Warn: 25_000 ms.
- Source of truth: bytes written at the recorder sample rate (16 kHz), not wall clock.
- `AudioRecorder` reports bytes after each read. Controller maps `Tick` on the main thread.
- At LIMIT: same `stopAndTranscribe()` as a mic tap. No dialog.
- IME hide / destroy while listening: `cancel()`, no auto-insert into the next field.
- Haptic once when crossing into WARN.

`RecordingLimiter` is pure Kotlin:

```kotlin
class RecordingLimiter(val maxMs: Long = 30_000, val warnMs: Long = 25_000) {
    fun onBytes(pcmBytes: Int, sampleRate: Int = 16_000): Tick
}
enum class Phase { LISTENING, WARN, LIMIT }
data class Tick(val elapsedMs: Long, val remainingMs: Long, val phase: Phase)
```

## Typing essentials

- Number row on LETTERS only.
- Swipe left on backspace: delete previous whitespace-delimited word. Hold-repeat stays character delete. Selection deletes first.
- Double-space period: two spaces within 500ms after a letter/digit become `. `. Off in URI / email / password / number fields. Pref default on.
- Sentence caps: if shift is OFF and text before cursor is empty or ends with `.?!` plus optional whitespace, next letter is uppercase. Same field exceptions. Pref default on.
- Globe: `🌐`, left of mode key, hidden when `shouldOfferSwitchingToNextInputMethod()` is false.
- Cursor bar (long-press space toggle): `⟨ word` · `⟨` · `sel` · `⟩` · `word ⟩`. `sel` latches shift+DPAD selection. Second long-press space or mode change hides it.

## Emoji picker

`😀` replaces the four key rows with a picker. Bottom utility row stays.

- Asset `assets/emoji/catalog.json` generated by `scripts/generate_emoji_catalog.py`.
- Groups: Smileys & Emotion, People & Body, Animals & Nature, Food & Drink, Travel & Places, Activities, Objects, Symbols, Flags.
- Item: `emoji`, `group`, `subgroup`, `name`, `keywords[]`. Tone-capable entries have `base` + `tones[6]`.
- Search filters `name` + `keywords`. Recents: 24 most recently committed, skipped in incognito.
- Grid: 8 columns. Long-press tone-capable → existing popup.
- Commit stays in emoji mode until `ABC`.

## Clipboard

```kotlin
data class ClipItem(val id: String, val text: String, val createdAtMs: Long)
class ClipboardStore(private val file: File) {
    fun snapshot(): List<ClipItem>
    fun capture(text: String, nowMs: Long): CaptureResult
    fun delete(id: String)
    fun clear()
}
sealed class CaptureResult {
    data class Added(val items: List<ClipItem>) : CaptureResult()
    object Ignored : CaptureResult()
}
```

- File: `filesDir/clipboard.json`. Cap 20. Head-duplicate ignored. >8 KB ignored. Text only.
- Listener registered in `onStartInputView`, unregistered in `onFinishInputView` / `onDestroy`.
- Skip: incognito, `IME_FLAG_NO_PERSONALIZED_LEARNING`, password/PIN variations, `ClipDescription.EXTRA_IS_SENSITIVE` / `android.content.extra.IS_SENSITIVE`, blank text.
- Panel: left chrome chip. Tap pastes and stays. Swipe or × deletes. Clear-all is a 2s confirm (`Clear?`).

## Autocomplete

- Asset `assets/dictionary/en.txt`: one lowercase word per line, frequency implied by order (earlier = more common). ~10k high-frequency English words.
- Current-word prefix match. 3 suggestions.
- Rank: learned count desc, then wordlist rank, then alphabetical.
- Tap replaces the in-progress word via `deleteSurroundingText` + `commitText`.
- Learn on word boundary (space, enter, punctuation) unless incognito or `IME_FLAG_NO_PERSONALIZED_LEARNING`.
- Learned store: `filesDir/unigrams.json`, cap 2000, drop lowest count on overflow. Min length 2. Letters only.
- No next-word prediction this pass.

## Prefs

Existing: haptic, autoSpace, activeModelId.
New: incognito (default false), doubleSpacePeriod (default true), sentenceCaps (default true).

Settings switches for all three. Incognito also honors the IME flag. Strip shows a lock glyph when learning/clipboard capture is frozen.

## Privacy / F-Droid

No new network. Models still download only when the user taps Download. Learner, clipboard, emoji recents stay on device.

## Testing

Pure Kotlin modules get JUnit tests (same style as `ModelCatalogTest`).
IME wiring is exercised by controller-level logic tests where Android types can be avoided; UI smoke is manual on device.

## Out of scope (backlog)

Swipe-to-type, one-handed mode, keyboard resize, GIFs/stickers, themes, extra locales, cloud sync, streaming captions, auto-chunk past 30s, custom long-press tables, pinned clips, images on clipboard.
